A function of two variables is a rule which assigns a number to each ordered pair of real numbers, $\left(x,y\right)$ from a given domain $\mathbb{D}$, which is denoted $f\left(x,y\right)$.  The set $\mathbb{D}$ is known as the domain, and its range is the set of real values obtained as output of $f$.  

> [!question] Why do we sometimes say 'codomain' and other 'range'?
> Range is the set of numbers from which the values of some function reach, whereas codomain is the set of number from which the range belongs.
