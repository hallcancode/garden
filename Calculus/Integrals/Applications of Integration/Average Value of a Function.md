The average value of a [[Introduction to Functions|function]] is a common application of [[Introduction to Integrals|integrals]]. Consider a function $f\left(x\right)$ across an interval $\left[x_0,x_1\right]$, the average value $\bar{f}$ on this interval is:
$$
\bar{f}=\frac{1}{x_1-x_0}\int_{x_0}^{x_1}f\left(x\right)dx
$$
