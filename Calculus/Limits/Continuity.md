A [[Introduction to Functions|function]] is deemed *continuous* at $a$ if the [[Introduction to Limits|limit]] of the function as its input approaches $a$ is equal to the value of the function at $a$.  More formally, we may write that:
$$
\lim_{ n \to a^- } f \left( n \right) =
\lim_{ n \to a^+ } f \left( n \right) =
f(a)
\iff f \text{ is continuous at }a.
$$
A function may also be continuous for an interval, including its entire domain.  

> [!info] Theorem
> Suppose that functions $f$ and $g$ are continuous at $a$.  Let $c$ be some constant, then the following functions are continuous at $a$:
> 
>  - $f+g$
>  - $f-g$
>  - $cf$
>  - $fg$
>  - $\frac{f}{g}$, so long as $g \left( a \right) \ne 0$

Additionally, all polynomials are continuous for all real numbers ($\mathbb{R}$) and all rational functions are continuous wherever defined.  

Limit laws state that, for a function $f \left( x \right)$ which is continuous near $a$, the limit of $f \left( x \right)$ is given by the expression:
$$
\lim_{ x \to a} f \left( x \right) = f \left( \lim_{ x \to a } x \right) 
$$
