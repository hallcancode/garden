A relation allows us to map the values of sets together to demonstrate that there is some “link” or common factor between the two values.  [[Introduction to Functions|Functions]] are a common form of relation, and are very useful to model many types of relationship, but not all relationship are one-to-one.  The broader scope of relations allows us to model different types of relationships.

> [!abstract]
> A *relation* on the set $S$ is a subset of the set $S \times S$ .  When two elements are related through the relation we write: 
> $$x \sim y$$
> Where we would say “$x$ is related to $y$.”

An example of a relationship which functions cannot model is a relation of a set that contains a loop, this would make the relation not one-to-one.  Any relation can be modeled with both a [[Graph|graph]] and a [[Set|set]].  

> [!example] Example #1
> Consider the set $W$, such that:
> $$W=\left\{\text{website addresses}\right\}$$
> Now we can consider different sets using this set, like ${W}\times{W}$.  From here, we can write subsets of this set, so for an example, determine the set $X$:
> $$\begin{align}
> X&\subset{{W}\times{W}}\\
> X&=\left\{\left(a,b\right) | \text{ There is a link from }a\text{ to }b, b\text{ is in Idaho.}\right\}
> \end{align}$$

> [!example] Example #2
> Suppose that $S$ is a set of numbers, such that $S=\{3,4,5,\dots,20\}$.  Define some relation of $S$, such that $(a,b)$ (a is related to be) if and only if $a|b$ ($a$ divides $b$.)

An $r$-graph, is a directed graph that shows the relationship of a set.  We do not always need to draw a connection between points of an $r$-graph, such as some behaviors of [[Equivalence Relation|equivalence relations]].  When we choose to represent relationships textually, and we have two things $x$ and $y$ that are related we may write:
$$
x \sim y
$$
