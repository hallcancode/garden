*Sets* are mathematical structures that describe [[Introduction to Relations & Equivalences|relationships]], as they are collections of elements that share some property.  *Elements* are the member items of a set, to denote that an element $x$ is present within a given set $S$, we write $x \in S$.  

Defining and writing sets can be done in two ways.  The first is by listing the elements of the set, for an instance, if a set $S$ contains the elements $x_1, x_2, \dots, x_n$ then we write:
$$S=\left\{x_1,x_2, \dots, x_n\right\}$$
We may also write a set in terms of the common properties of the elements of that set.  This is done through *set builder notation*:
$$\left\{x \in S | x \text{ has property }p\right\}$$
The elements of a set are contained within some *universal domain*, which includes all things that could be dissected.  Typically, when dealing with human language, the universal set is implied.  Within set theory we typically use the set name $U$ to denote the universal set.

> [!example] Examples of Universal Domains
>  - If we have a set of all students in MATH 1760, our universal domain may be all students at the University of Idaho.  
>  - If our set is all classes offered at the University of Idaho that Washington State University students can take, our universal set may be the course catalog for WSU students.  

## Common Sets
Some sets are common enough that they are granted their own symbol, include the sets of all:

- Natural numbers: $\mathbb{N}$. 
- Integers: $\mathbb{Z}$.
- Real number: $\mathbb{R}$.
-  Rational numbers: $\mathbb{Q}$.
