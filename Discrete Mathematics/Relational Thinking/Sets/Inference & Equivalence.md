Since we already know that there is a relationship between the [[Logical Connectives|logical connectives]] of formal logic and [[Set Logic|set logic]], we can begin to follow the same rules for [[Derivation & Proof|derivations and proofs]] as before.  Within set theory, we say that two elements are equal if, and only if, they contain all of the same elements.  For an instance, $A=B$, such that:
$$
A=B \iff \left(\forall x\right) \left(\left(x \in A\right) \longleftrightarrow \left(x \in B\right)\right)
$$
Using this definition we can use our equivalence relations from before:

| Equivalence                                                                                                            | Name                 |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------- |
| $$\left(A \cap B\right)^\prime = A^\prime \cup B^\prime$$<br>$$\left(A \cup B\right)^\prime = A^\prime \cap B^\prime$$ | **De Morgan's laws** |
