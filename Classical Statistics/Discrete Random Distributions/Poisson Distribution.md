The *Poisson random variables* arise as the number of events that happen with a certain rate.  We write $X \sim \text{Poi}\left(\lambda\right)$ as a shorthand notation for a Poisson random variable.  This means that $X$ is a random variable with the pmf:
$$
	P\left(X = x | \lambda\right) = 
	\frac{e^{-\lambda} \lambda^x}{x !}
$$
Such that the number of events $X \in \mathbb{Z}$, where the rate parameter is given as $\lambda \in \left(0, \infty\right)$.
